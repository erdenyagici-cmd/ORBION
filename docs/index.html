Kurulum

Üç komut, sonra panel

Tek gereksinim: Python 3.10+ ve bir sunucu.

# 1) klonla
git clone https://github.com/erdenyagici-cmd/ORBION.git
cd ORBION

# 2) yapılandır
cp .env.example .env        # sağlayıcı anahtarlarını gir
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt

# 3) çalıştır (panel :8090)
python3 scripts/agent.py

Sonra http://localhost:8090/operations.html adresini aç ve PANEL_PASSWORD ile giriş yap.
