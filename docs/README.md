# ORBION — GitHub Pages (docs klasörü)

Bu klasör GitHub Pages ile yayınlanır.

## Etkinleştirme (tek seferlik)

1. https://github.com/erdenyagici-cmd/ORBION/settings/pages
2. **Build and deployment → Source** = **Deploy from a branch**
3. **Branch** = `main` · **Folder** = `/docs`
4. **Save**

1-2 dakika sonra site yayında:

**https://erdenyagici-cmd.github.io/ORBION/**

## Custom domain (opsiyonel)

`orbion.duckdns.org` gibi bir alan adı bağlamak için aynı sayfada
**Custom domain** alanına yaz. DNS tarafında CNAME kaydı gerekir.
